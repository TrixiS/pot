# pot

```shell
go install github.com/TrixiS/pot
```

```bash
SSH tool

Usage:
  pot [command]

Available Commands:
  add         Add a new connection
  completion  Generate the autocompletion script for the specified shell
  connect     Make an SSH connection
  ftp         SFTP file manager
  help        Help about any command
  list        List connections
  migrate     Migrate from mantra database file
  remove      Remove a connection
  reveal      Reveal connection password
  tunnel      Make SSH tunnel
  update      Update connection configuration

Flags:
  -h, --help   help for pot
```
